# Backup: editorial homepage

A copy of the live homepage (`index.html` and `stylesheet/css/editorial-portfolio.css`) taken on 2026-11-15,
before the new design (formerly `index-v6.html`) replaced it. `DESIGN.md` describes this design.

- `index.html` – the page. Images, favicons and the CV are linked from the project root (`../../`).
- `css/editorial-portfolio.css` – its stylesheet.

To restore it: copy `index.html` back to the project root, change the stylesheet link to
`stylesheet/css/editorial-portfolio.css`, remove the `../../` from the other links, and copy the CSS file back to
`stylesheet/css/`.
