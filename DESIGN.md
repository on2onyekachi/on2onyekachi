## Overview

A personal portfolio presenting Onyekachi Okwuolisa's selected digital products and development practice. The visual direction pairs oversized serif identity with a minimal, image-led work index and a single cobalt accent.

## Colors

Keep the canvas and text high contrast. Reserve the primary color for the second name line, links, and small directional cues. The dark theme retains the same roles and hierarchy.

## Typography

Use the editorial serif for identity, project titles, body copy, and navigation. Separate display identity from project headings through scale and spacing; keep supporting labels quiet and readable.

## Layout

Let the portrait card overlap the oversized name within a viewport-height introduction. Keep project descriptions beside landscape previews on wider screens, then stack each preview below its description on narrow screens. Align the work and about content to the same page gutter.

## Elevation & Depth

Use depth only to lift the portrait identity card from the page. Project previews remain flat and are framed by a fine border.

## Shapes

Keep image frames nearly square-cornered. Use fine rules to separate project entries and text links instead of boxed project cards.

## Components

Each project entry follows the same scan order: category, title, concise description, text actions, and a landscape preview. The portrait card groups the profile image, name, role, and direct contact link.
